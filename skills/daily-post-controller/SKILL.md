# 公众号日更总控（星辰聊读书专用）v2

本技能所有文件都在 **SKILL.md 所在文件夹**（下文称 `<技能目录>`）：

```
knowledge/00-persona-and-banned-words.md   ← 人设和红线，每一步都先读
knowledge/01-topic-and-title.md         ← 选题规则 + 标题公式
knowledge/02-body-and-revision.md         ← 结构 + 硬要求 + 改稿步骤
knowledge/03-reusable-hits.md       ← 哪些方向验证过能爆、哪些已证伪
knowledge/04-my-real-stories.md       ← 她的真事库（自动模式只能从这里取材）
knowledge/05-tutorial-hard-rules.md     ← 从加号教程原文提炼的操作标准，写稿时逐条对照
knowledge/06-verified-quotes.md         ← 从她自己爆文里抽出的语录，引号内容的唯一来源
check_ai_taste.py                  ← AI味打分 + 未填空拦截
posts/<日期-标题>/article.md       ← 每篇成稿
posts/log.md                      ← 发过什么、用了哪种结构
```

本技能会调用另外两个技能：`gzh-cover`（封面）和 `wechat-mp-publisher`（推草稿箱）。没装就跳过对应步骤并明确告诉用户。

---

## 一条铁律（先读这段）

公众号新规明文禁止「利用 AI 替代真人完成内容创作、发布」。教程原文：**AI 只给思路、新知、金句、案例；正文要有作者自己的经历和语气**。所以本技能的定位是「AI 搭骨架，她填血肉」，不是代笔：

1. 正文里所有个人经历**只能来自两个地方**：她当场补的（补充模式），或 `knowledge/04-my-real-stories.md` 里已有的（自动模式）。**禁止凭空编造她的人生细节**——数字、人名、事件、对话，一个都不能造。
2. 每篇必须经过她**预览确认**才推草稿箱。她没说「可以」，不推。
3. 只推草稿箱，永远不群发。群发是她在后台亲手点的。

## 用户怎么说都行

| 她说 | 你做 |
|---|---|
| 「今天写一篇」「写篇存钱系列的」 | **补充模式**（默认）：走到第 5 步停下，等她填空 |
| 「今天自动出一篇」「自动来一篇天道」 | **自动模式**：从素材库取真事，走到第 7 步预览 |
| 「用这个标题写：XXX」 | 跳过选题标题，直接第 4 步 |
| 「补好了」「填完了」 | 接第 6 步 |
| 「可以」「推吧」「就这样」 | 接第 8 步推送 |
| 「再推一次」 | 只重跑第 8 步（通常是填完 IP 白名单之后） |
| 「第 X 段改成……」「标题换成……」 | 改完重新第 7 步预览 |
| 「上一篇爆了，跟一篇」 | 走文末「命中放大」 |

中途不要追问她别的问题。她只在两个地方参与：填空、看预览。

## 执行步骤

### 第 0 步：开工前必读

1. `knowledge/00` 全文（人设+禁用词）
2. `knowledge/05` 全文（教程硬规则）
3. `knowledge/04`（素材库）——知道她手里有哪些真事，选题时就往能用上素材的方向靠
4. `posts/log.md` 最近 5 行——本篇的**系列、结构、标题公式**三样都不能和上一篇相同；连续 3 篇不能同一结构（教程：结构相同只换关键词 = 被判「套路化模版写作」的直接原因）

### 第 1 步：定系列

用户没指定时按 70/20/10：**70% 天道 + 吸引力法则轮换，20% 存钱/心理学书，10% 新方向试水**。`knowledge/03` 第三节「已证伪」方向不碰。

### 第 2 步：选题（内部完成）

按 `knowledge/01` 选题 prompt 出 5 个，自己挑 1 个。挑选顺序：
1. 能用上 `knowledge/04` 里某条真事的优先
2. 「大众共性痛点」优先于「个人小情绪」（教程：写所有人的心事，不写自己的私事）
3. 具体场景 + 数字 + 人群三样齐

### 第 3 步：标题

按 `knowledge/01` 出 10 个，再用 `knowledge/05`「标题」节过一遍，挑 1 个。**公式优先级：她自己账号验证过的 > 教程验证过的**——她的天道系列 26 篇均值 6200、最高 6.2 万，用的是公式 A「丁元英：+ 一段有观点的长话，藏一个数字或反转」；吸引力法则系列用的是公式 B「《吸引力法则》：+ 直接对读者说话的好运暗示」。同系列默认先用她的公式，教程公式（人群+数字+价值对比、名人+痛点、痛点+心理学概念等）作为轮换和 AB 对照的备选。硬要求：
- 必须含可分发标签之一：书名 / 人名（丁元英、《吸引力法则》）/ 身份词（退休、50岁、中年女人）/ 数字
- **搜一搜借公式可以，但必须换人群/定位**，不能原样搬别人标题
- 标题里的核心词（丁元英 / 吸引力法则 / 存钱）放前 15 个字内，让系统打标签
- 不能是「如何 / 怎样」开头（她的数据：平均 14 阅读）
- **少用负面词**（失业、失败、越来越差、全完了）——读者抵触，平台也会删「制造焦虑」的文；三类标题绝对不发：停更/封笔类、博眼球焦虑类、虚假承诺类 [4845251115118888][55522114184825214]
- 每个标题要能说出踩了 6 类人性钩子里的哪一个：恐惧 / 身份认同 / 贪婪 / 懒惰 / 利益 / 好奇 [4845558515158428]

记下落选里最好的 2 个当备选。

### 第 4 步：搭正文骨架

**字数 900–1200**（教程：1000 字左右最合当下耐心；≥900 字且分段合理可插 2 条广告）。Markdown 格式，第一行 `# 标题`，正文不重复标题。

结构从下面选一个（和 `posts/log.md` 上一篇不同）：
- **A 并列清单体**：开头 → 3–4 个并列点（每点小标题 + 200 字左右：原因→案例→怎么做）→ 结尾。教程最推荐新手用。**注意各点内部写法要错开**：不能每一点都「语录→我的事→概念→金句」同一顺序，至少一点不用语录开头（段落过于对称本身就是套路化特征）
- **B 是什么-为什么-怎么办**：概念（心理学效应/丁元英一句话）→ 为什么重要 → 怎么用
- **C 语录展开**：一句核心语录 → 现实场景验证 → 反例 → 怎么做（天道爆文结构）
- **D 故事+感悟**：一件事贯穿 → 感悟 → 联系读者
- **E 观点碰撞**：大众观点 → 我的质疑 → 论据 → 修正版观点

每一处都要对照 `knowledge/05`：
- **开头 3–5 行**，最后一句必须是价值承诺「看完这篇你会……」，不能只说痛不给价值
- **每个小标题是「认知之外」的反转句**（「你考虑的不是别人，是怕不被喜欢的自己」这种），不是常识陈述
- 至少 1 个有名字的心理学概念/实验，最多 1 次名人语录，语录后必须跟她自己的一句总结
- 金句 2–3 句：开头一句击中、结尾一句能当转发语
- **结尾 4–5 行**，别长；提问式 / 行动式 / 反转式 / 金句式任选，不用「愿你 / 共勉」
- 单句 ≤25 字，一段 ≤3 行

**个人时刻的处理（两种模式的唯一区别）：**

**补充模式**：在 3–4 个最需要真实感的位置留填空，格式固定：
```
【补一件事：具体问题。例：你是在哪儿、正干什么时看到这句话的？当时第一反应？2-3句就行】
```
问题必须具体到「谁 / 什么时候 / 在哪 / 干了什么」，是填空题不是作文题。每处 2–3 句够用，全篇合计 100–200 字。

**自动模式**：从 `knowledge/04` 里挑 2–3 条最贴的素材原样或轻改后填入。用了哪几条要记下来。素材库剩余不足 8 条时，汇报里加一句「素材快用完了，抽空跟我讲几件新鲜事」。

### 第 5 步：交给她填空（仅补充模式）

把带填空的稿子完整给她看，前面加一句：

> 骨架搭好了，有 3 处要你补几句真事，直接在方括号那儿写就行，别管衔接。写完说「补好了」。

然后**停下等她**。她回来后把她写的话接顺（只改衔接和错字，不改她的口气和内容），进第 6 步。

### 第 6 步：自检

保存到 `<技能目录>/posts/<YYYY-MM-DD>-<标题前8字>/article.md`，运行：

```bash
cd <技能目录>
python check_ai_taste.py "posts/<日期-标题>/article.md"
```
（`python` 不行试 `py`。）

- 有未填的【补一件事】→ 脚本会直接拒绝，回第 5 步
- 评分 ≥2.5 → 按 `knowledge/02` 改稿 prompt 改，最多 3 轮
- 通过后再自己读一遍：**像不像 50 多岁退休阿姨跟老姐妹聊天？** 不像继续改

### 第 7 步：预览确认（每篇必走）

调 `gzh-cover` 出封面。然后**按读者最终看到的样子**给她预览，格式固定：

```
📱 预览 ——————————

标题：xxx
封面：（贴 square_preview.png，说明这是转发时别人看到的小图）

（正文全文）

——————————
本篇：天道系列 / 结构A / AI味 1.5
你补了 3 处、共 156 字（或：用了素材库第 4、11 条）

没问题回「可以」我就推草稿箱；要改哪段直接说。
```

她说「可以 / 推吧」→ 第 8 步。她提修改 → 改完重新预览。

### 第 8 步：推草稿箱 + 记录 + 汇报

调 `wechat-mp-publisher`：`--markdown` 本篇 article.md，`--cover` cover.png，`--digest` 正文第一段前 50 字。

**推送报 40164（IP 不在白名单）时**：这不是文章的问题，是她家宽带 IP 变了。把脚本打印出来的那个 IP 和三步指引原样转给她（公众号后台 → 设置与开发 → 基本配置 → IP 白名单 → 添加），告诉她填完等 30 秒说「再推一次」。**不要自己反复重试**；文章和封面都已保存，不用重做。她说「再推一次」就只重跑本步。

`posts/log.md` 追加一行（日期 / 系列 / 结构 / 标题公式 / 标题 / AI味 / 模式 / 状态）。

汇报：

> ✅ 推到草稿箱了。去公众号后台看一眼排版就能群发，建议早 6 点或晚 8 点发。
> 备选标题：① …… ② ……

## 测试期（前 2–3 周）：同选题双版本，靠数据定写法

教程规则来自影评/育儿/职场赛道，她的公式来自她自己的号，哪套更适合她的读者，**只能用她账号的数据回答**。所以开头 2–3 周：

- 同一个选题出两版：**A 版**用她验证过的公式（标题公式 A/B + 结构 C 语录展开），**B 版**用教程公式（人群+数字+价值对比 + 结构 A 并列清单体）。隔天各发一篇，或主号副号各一篇（必须换结构重写，不是同文两发）
- `posts/log.md` 每篇标清版本，发后 3 天补三个数：阅读、打开率、留言数
- 两周后哪版明显好（阅读或打开率高 30% 以上），就以那版为主，另一版降到 20% 轮换
- 数据说话，不猜。她基线是中位数 20–84，先看有没有稳定破百再谈爆

## 命中放大

她说「上一篇爆了 / 阅读上万了」时：**同系列、同结构、同标题公式，只换语录 / 场景 / 数字**，反复出，**直到这个结构不再有流量为止**（教程原话），再回归轮换。每篇仍走填空或素材库 + 预览确认，不因为赶时间跳过。

## 红线（违反任何一条自己改掉再交）

- 不编造她的人生细节（数字、人名、事件、对话）。来源只有：她当场填的、`knowledge/04` 里有的
- 不引用不存在的心理学研究，不编数据
- 正文里**不出现任何引导点广告的话**（「点点文中广告」之类）→ 扣流量主收益甚至封号；不出现「送电子书/送资源」→ 侵权违规
- 平台判「AI生成未修改」「滥用原创」会关原创和留言功能——这就是为什么她必须填空/预览，AI 直出的稿子一律不推
- **引号里的话只能从 `knowledge/06-verified-quotes.md` 取**（那是从她自己几万阅读的文章里抽出来、经读者检验过的）。库里没有的句子一律转述、不加引号、不标章节；库里没有的书不写（先让用户把那本书的划线导进 06 再写）。她的读者看过剧读过书，一句伪语录就在评论区翻车
- 心理学概念/实验只用「有名字」的表述，**不带百分比、年份、样本量**——名字可查，数字基本是 AI 凑的
- 预览时每句引用后标 `✓库内` 或 `（转述）`，让她一眼看到哪些是真话
- 标题不原样搬别人的；借公式必须换人群/定位
- 连续 3 篇不同结构、不同标题公式
- 不出现 `knowledge/00` 禁用句式
- 没有她的「可以」不推；只推草稿不群发
- 同一篇不主号副号都发；副号发必须换结构重写
