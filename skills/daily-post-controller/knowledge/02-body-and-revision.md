# 02 - 正文prompt + 改稿prompt

> 用法：先拼 `00-persona-and-banned-words.md`，再拼本文件对应环节。

---

## 正文prompt

```
为标题「[标题]」写正文，1500-2000字。

结构：从以下5种中选与上一篇不同的一种（告诉我你选了哪种）：
A. SCQA悬念式：场景→冲突→疑问→答案
B. 故事+感悟式：一个完整的个人/他人故事贯穿全文
C. 热点六步式：事件→社会议题→情绪→如果是我→观点→金句
D. 语录展开式：一句核心语录→现实场景验证→反例→怎么做（天道爆文结构）
E. 对话辩论式：先立一个大众观点→反驳它→给出新答案

硬性要求：
1. 开头3行内必须有钩子（场景/冲突/反常识），最后一句要让人想往下读
2. 必须含1个「个人时刻」（见人设文件，要具体有画面）
3. 必须含1个具体新知：真实心理学概念/实验/数据，写出名称
4. 正文按「新知→案例→收回观点」循环2-3轮
5. 名言引用最多1次，且必须跟上你自己的反应或反驳
6. 敢表态：至少1个可以被反驳的观点
7. 结尾禁止「愿你/共勉」，从这4种选：提问式/行动指令式/反转式/留白式
8. 全文过一遍禁用词清单
```

---

## 改稿prompt

```
检查并改写下面这篇文章，按顺序执行：

1. 【AI味扫描】找出所有禁用句式、虚化表达（看过一个故事/有人说）、连续排比、每段结尾升华——列出并改掉
2. 【个人声音检查】是否有具体的个人时刻？没有就在最合适的位置插入一个
3. 【口语化】把所有书面腔改成能读出声的话；单句>25字的拆短
4. 【观点锐化】结论是不是安全的中庸话？改成敢被反驳的表态
5. 【开头钩子】前3行能不能让人停下滑动的手？不能就重写
6. 【结尾】如果是总结式/祝愿式，改成提问/行动/反转/留白

输出：修改后全文 + 修改点清单

[粘贴文章]
```
