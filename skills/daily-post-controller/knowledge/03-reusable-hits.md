# 历史爆文复用清单

> 原则：低粉爆文最值得拆——已验证有人点、有人转。只换素材，不换结构。

## 一、两大流量密码（优先无限复用）

### 1.《天道》丁元英系列 — 26篇，平均6200，最高62090
结构基因：`丁元英/《天道》：+ 长语录式观点 + 具体数字/场景 + 反常识`

可直接衍生的新选题（四招复制法）：
- 换关键词：「年收入不到10万别搞认知提升」→「存款不到5万，别急着搞副业」
- 换场景：领导传话→「同事突然对你客气」「亲戚开始跟你借钱」
- 换人物：丁元英→韩楚风/芮小丹语录；同类剧《大江大河》《显微镜下的大明》
- 反义词：「过度节俭省下的是廉价人生」→「过度大方，散掉的是你的底气」

### 2.《吸引力法则》玄学好运系列 — 19篇，平均7547，最高38094
结构基因：`《吸引力法则》：+ 直接对读者说话的好运暗示`（点赞率极高，粉丝粘性强）
- 「恭喜你要转运了，否则你看不到这篇文章」→ 无限换壳：「你的苦快到头了」「8月对你有大安排」
- 同类书扩展：《秘密》《当下的力量》《臣服实验》《能量》

## 三、明确放弃的方向（数据证伪）

- 「如何/怎样」教程式标题（平均阅读14）
- 抽象成长概念文：自律/断舍离/富养自己（大量阅读<50）
- 写作教学、财富心法类（垫底文章重灾区）
- 传统书评长文（2023年老路线，平均阅读几十）
