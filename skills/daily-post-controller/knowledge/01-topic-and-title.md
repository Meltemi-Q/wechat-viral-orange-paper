# 01 - 选题prompt + 标题prompt

## 选题prompt

```
你现在帮我做公众号选题。我的账号是书评/成长号，历史数据验证过的流量密码（按优先级）：
1.《天道》丁元英语录+现实场景解读（26篇平均阅读6200，最高6.2万）
2.《吸引力法则》玄学安慰+好运暗示（19篇平均7547，最高3.8万）
3.《蛤蟆先生去看心理医生》等心理学书+情绪痛点（单篇2.8万）
4. 名人书单盘点（文淇42本书1.3万、邵艺辉51本6227）
5. 职场具体场景故事（同事被解雇秒删好友，5722）

选题规则：
- 从上面5个方向选，或给出与热点结合的新方向
- 每个选题必须落到「具体场景/具体数字/具体人群」，禁止抽象概念
  [合格]「工资5000存不下钱的人，缺的不是自律是这个」
  [拦截]「如何养成存钱习惯」
- 用四招复制法从旧爆款衍生：换关键词/反义词/词汇类比/换新说法
- 每个选题标注：目标情绪（焦虑/爽感/被安慰/好奇）+ 目标人群

今天的输入：[粘贴热点事件/想写的书/最近的情绪]

输出5个候选选题，按预估爆款潜力排序，各附一句理由。
```

## 标题prompt

```
为选题「[选题]」生成标题。我的账号验证过的高打开标题基因：

公式A【语录+场景长标题】（天道系列，最高6.2万阅读）：
[人名/书名]：+ 一段有观点的长话，中间藏一个具体数字或反常识转折
例：丁元英：如果你年收入不到10万，不要花太多时间在认知提升上，因为……

公式B【玄学好运钩子】（吸引力法则系列，最高3.8万）：
[书名]：+ 直接对读者说话的好运暗示
例：《吸引力法则》：恭喜你要转运了，否则你是看不到这篇文章的

公式C【反差颠覆】（攻略核心公式）：
不是A，而是B / 反向行为
例：想做好个人IP，一定要放弃日更写作

公式D【名人+数字书单】：
例：文淇力荐！42本书让你做思想丰富的自信女孩

公式E【具体职场/生活故事】：
用一句话讲完一个有冲突的完整事件
例：早上一位同事被解雇，立刻退出工作群，中午组长联系，发现被删……

要求：
- 每个公式各出2个，共10个标题
- 标题里必须有可分发标签（书名/人名/身份词/数字）
- 自查：是不是正确废话？能不能再具体一点？
- 严格避开禁用句式清单
```

---

## 标题自查清单（人工过一遍）

- [ ] 有可分发标签（书名/人名/身份/数字）？
- [ ] 有反差或好奇缺口，不是正确废话？
- [ ] 和近10篇是同一风格家族？
- [ ] 没用任何禁用句式？
- [ ] 读完标题会想「为什么/然后呢」？
